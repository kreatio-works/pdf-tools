# PDF Tools — ブラウザで動くPDF統合・分割ツール

インストール不要・ブラウザで開くだけで使えるPDFツールです。
**ファイルはすべて端末内で処理され、サーバーには一切送信されません**（pdf-lib使用・オフラインでも動作）。

A free in-browser PDF tool. **All processing happens on your device — files are never uploaded.**

## 使う / Use it

- **日本語版**: https://kreatio-works.github.io/pdf-tools/
- **English**: https://kreatio-works.github.io/pdf-tools/en.html

## できること / Features

- **統合 / Merge** — 複数のPDFを1つに結合（ドラッグで並べ替え可能）
- **抽出 / Extract** — 指定ページだけを抜き出して1つのPDFに
- **分割 / Split** — 指定位置で分割、または1ページずつ分割（ZIPでダウンロード）

PC・Mac・iPhoneのブラウザで動作します。/ Works in any modern browser on PC, Mac and iPhone.
